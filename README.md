# TrustCart AI
1. Node.js 18+ install karein.
2. https://www.scrapingbee.com par key lein (free trial) -> SCRAPER_API_KEY (sabhi sites ke liye). Amazon ke behtar data ke liye optional RAINFOREST_API_KEY.
3. `.env.example` ko `.env` banakar keys paste karein.
4. `npm install` phir `npm start` -> http://localhost:3000
Jo data page/provider nahi deta wo "Data Unavailable" dikhta hai. Kuch sites block kar sakti hain; koi guarantee nahi.
